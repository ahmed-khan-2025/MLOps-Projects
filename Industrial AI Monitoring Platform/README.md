# Industrial AI Monitoring Platform

A containerized **Industrial AI and Predictive Maintenance platform** for monitoring machine sensor data in real time and generating machine-failure predictions using Machine Learning.

The platform simulates industrial machines, stores sensor data in PostgreSQL, exposes data through a FastAPI backend, performs ML-based failure prediction, and provides a React + TypeScript monitoring dashboard.

---

## 🚀 Project Overview

The goal of this project is to demonstrate an end-to-end **Industrial AI / MLOps monitoring architecture**:

```text
Industrial Machine Simulator
          │
          ▼
     Sensor Data
          │
          ▼
       FastAPI
          │
          ▼
     PostgreSQL
          │
          ├───────────────┐
          │               │
          ▼               ▼
   Sensor Readings    ML Prediction
          │               │
          └───────┬───────┘
                  │
                  ▼
        React Monitoring UI
                  │
                  ▼
       Real-Time Dashboard
```

The system is designed as a foundation for future integration with real industrial data sources such as:

* OPC UA
* PLC systems
* SCADA
* MQTT
* Industrial IoT gateways
* Real sensors
* Manufacturing systems

# 🐳 Docker Architecture

The complete application runs using Docker Compose.

```text
                 Docker Compose
                       │
       ┌───────────────┼────────────────┐
       │               │                │
       ▼               ▼                ▼
  PostgreSQL        Backend          Simulator
   :5432             :8000
       │               │
       │               │
       └───────┬───────┘
               │
               ▼
          React Frontend
             :5173
```

From the Windows host, PostgreSQL is exposed on:

```text
localhost:5434
```

The backend is exposed on:

```text
localhost:8004
```

The frontend is exposed on:

```text
localhost:5173
```

# ⚙️ Environment Configuration

Configuration is stored in `.env`.

Example:

```env
POSTGRES_DB=industrial_ai
POSTGRES_USER=industrial
POSTGRES_PASSWORD=industrial
POSTGRES_HOST_PORT=5434

DATABASE_URL=postgresql://industrial:industrial@postgres:5432/industrial_ai

MODEL_PATH=/app/ml/model.joblib

BACKEND_HOST_PORT=8004
FRONTEND_HOST_PORT=5173
```

> The `.env` file should not be committed to GitHub if it contains passwords or other secrets.

Create `.env.example` for public repositories.
